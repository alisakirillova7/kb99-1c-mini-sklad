# Проект «Мини-Склад»

Учебная конфигурация на платформе 1С:Предприятие 8.3.

## Что внутри:
- Справочники: Товары, Контрагенты
- Документы: Поступление, Реализация
- Подсистема: Мини-склад

## Как открыть:
1. Создайте новую пустую информационную базу в 1С.
2. В Конфигураторе выберите «Конфигурация» -> «Загрузить конфигурацию из файлов...».
3. Выберите папку с данным репозиторием.
